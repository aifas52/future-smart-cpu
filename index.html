Architecture Reference & Viva Prep

Learn Computer Architecture

Core concepts behind single-cycle execution, five-stage pipelining, RAW hazards, data forwarding, and performance equations.

1. CPU Core Architecture

A CPU executes programs by coordinating four core blocks:

  • Registers (R1–R3): Ultra-fast on-chip storage holding active operands and results.
  • Control Unit (CU): Fetches instructions, decodes opcodes, and generates control signals.
  • ALU: Executes arithmetic operations (ADD, SUB, MULT, DIV) on input operands.
  • Instruction Counter: Tracks how many instructions have completed execution.

2. Five Pipeline Stages

Pipelining overlaps instructions like an assembly line so five instructions can be in flight simultaneously:

  • IF (Instruction Fetch): Reads the next instruction from memory.
  • ID (Instruction Decode): Decodes opcode and reads source registers.
  • EX (Execute): ALU computes arithmetic results or moves immediate values.
  • MEM (Memory Access): Data memory stage (pass-through for ALU/MOV instructions).
  • WB (Write Back): Writes the final result into the destination register.

3. Data Dependencies & RAW Hazards

A RAW (Read After Write) hazard occurs when a later instruction reads a register before an earlier producer completes WB. 

I1: ADD R3, R1, R2   // writes R3 in WB (Cycle 5)
I2: SUB R2, R3, R1   // needs R3 in ID/EX (earlier!)

In an in-order pipeline, WAR and WAW hazards do not cause stalls because reads occur strictly in ID and writes occur strictly in WB in program order.

4. Pipeline Stalls vs Data Forwarding

Without forwarding, the consumer stalls (inserts waiting cycles called bubbles) until the producer reaches WB:

  • Distance 1 (I1 → I2): 2 stall cycles without forwarding.
  • Distance 2 (I1 → I3): 1 stall cycle without forwarding.
  • Distance ≥ 3 (I1 → I4): 0 stalls — WB completes in time.

Data Forwarding (Bypassing) routes the computed ALU output directly from EX/MEM or MEM/WB pipeline registers to the consumer's ALU input, cutting data stalls to zero for ALU/MOV instructions.

5. Performance Formulas

Ideal Pipeline Cycles (N instructions, 5 stages) Cycles = N + 4
Cycles Per Instruction (CPI) CPI = Total Cycles / N
Forwarding Speedup Speedup = Cycles(No Fwd) / Cycles(Fwd)
Pipeline Efficiency Efficiency = (N / Total Cycles) × 100%

6. Viva Quick-Check Q&A

Why does forwarding eliminate stalls for ADD followed by SUB?

Because ADD produces its sum at the end of EX, and forwarding sends it straight into SUB's EX stage without waiting for WB.

Why is Pipeline Efficiency below 100% even with 0 stalls?

Filling and draining the 5-stage pipeline adds 4 overhead cycles (N + 4 total). As N grows larger, efficiency approaches 100% (CPI → 1.0).

What happens on division by zero in Phase 1?

The Control Unit and ALU halt the instruction safely, preserve register values, increment nothing, and display an explicit error status.
